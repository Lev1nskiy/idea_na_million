# СИНАПС — AI-native CRM (хакатон-MVP)

Фронтенд-демо AI-native CRM по ТЗ v5: чат клиента, дашборд менеджера, Policy Management,
безопасность и метрики. Поверх REST-API работает детерминированный mock-движок (аналог `MockLLM`
из roadmap), поэтому **всё демо работает без внешних LLM-ключей и без БД**.

> Принцип надёжности из плана: «LLM говорит — код решает». Числа, скидки и SLA рождаются
> только в детерминированном коде поверх версионируемой Policy Matrix.

## Быстрый старт локально (5 минут)

Требуется только **Node.js 20+**.

```bash
npm install          # один раз
npm run build        # production-сборка
npm start            # → http://localhost:3000
```

Режим разработки с hot-reload:

```bash
npm run dev          # → http://localhost:3000
```

Postgres и `.env` **не обязательны**: демо-хранилище — в памяти процесса.
Для персистентности скопируйте `.env.example` → `.env` и укажите `DATABASE_URL`.

## Запуск в Docker (self-hosting)

```bash
docker compose up --build     # → http://localhost:3000
docker compose down
```

Профиль с Postgres (для персистентности):

```bash
DATABASE_URL=postgresql://postgres:postgres@db:5432/app_db docker compose --profile db up --build
```

## Подключение реального backend

UI — тонкий клиент: взаимодействие с API изолировано в `src/lib/api.ts`.
Чтобы подключить настоящий пайплайн (FastAPI + GigaChat из roadmap), достаточно:

1. Поднять backend, реализующий контракт `POST /api/messages` и остальные маршруты таблицы шага 5.
2. Выставить `NEXT_PUBLIC_API_BASE=http://127.0.0.1:8000` (и CORS на стороне backend).
3. Встроенный mock-движок при этом остаётся fallback-демо (офлайн-страховка на защите).

## Демо-сценарии (кнопки на странице чата)

1. **Справка (A)** — цена/наличие из каталога.
2. **Скидка (C)** — расчёт по Policy Matrix; продолжите «А 40%?» → предложение максимума → «Это неприемлемо» → эскалация.
3. **КП (D)** — коммерческое предложение по шаблону «Офис на 20 человек».
4. **Гарантия (G)** — замена за 24 ч по заказу из истории клиента.
5. **Спор (I)** — ACK <100 мс (pre-classifier) → HOLD → уведомление менеджеру на дашборде.
6. **Инъекция (F)** — детерминированный скрипт + инцидент безопасности; легитимная часть вопроса всё равно получает ответ.

Эффектный момент для защиты: на `/policy` нажмите «max_pct → 10%», сохраните,
и повторите сценарий «Скидка» — ответ ИИ изменится **без перезапуска** (политика читается на каждый запрос).

Кнопка «Сбросить демо-данные» в сайдбаре возвращает исходное состояние (41 диалог истории,
живой HOLD АО «НордБанк», актуальная версия политики).

## Архитектура

```
┌ UI (Next.js, App Router) ── тонкий клиент, бизнес-логики нет
│     /api/*  REST-контракт по таблице из roadmap шага 5
├ src/server/engine.ts   оркестратор: perception → understanding → decision → action → learning
├ src/server/store.ts    in-memory демо-стор + сид 41 диалога (заменяется на PostgreSQL)
├ src/server/templates.ts детерминированные шаблоны (F, ACK-спор, лимит скидки) — без LLM
├ src/lib/policy.ts      calcAllowedDiscount / calcDeliveryCompensation / getManagerSla
└ src/lib/privacy.ts     mask_pii (Ст. 4): телефоны, email, ФИО, серийники, суммы
```

Внешний backend (FastAPI из roadmap) подключается без изменения UI — через переменную
`NEXT_PUBLIC_API_BASE` (каналы остаются тонкими адаптерами над `POST /api/messages`).
